# KKN-11 Informatika: Website Gampong Dama Tutong

Repository ini berisi kode sumber untuk website profil dan informasi **Gampong Dama Tutong**, yang dibangun sebagai program kerja pengabdian masyarakat oleh KKN Kelompok 11 Teknik Informatika.

🔗 **Live Demo:** [damatutong.vercel.app](https://damatutong.vercel.app/)

## ✨ Fitur Utama
- **Profil Desa:** Informasi demografi penduduk, pembagian wilayah dusun, serta Visi & Misi gampong.
- **Pemerintahan Gampong:** Struktur aparatur gampong (Keuchik, Sekretaris, Kaur, Kasie, hingga Kepala Dusun) serta badan Tuha Peuet.
- **Potensi & Fasilitas:** Pemetaan sektor pertanian, perkebunan, peternakan, serta fasilitas umum di gampong.
- **Galeri & Informasi Sosial:** Dokumentasi kegiatan dan dinamika kehidupan sosial masyarakat.
